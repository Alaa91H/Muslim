# Security Policy

## Reporting a vulnerability
Do **not** open a public issue for suspected vulnerabilities.

Use GitHub's private **Report a vulnerability / Security advisory** flow when available. If it is unavailable, contact the maintainer privately using a contact method listed on the GitHub profile.

Please include the affected version/commit, impact, reproduction steps or proof of concept, relevant environment information, and redacted logs when available.

Security fixes are evaluated against the current default branch; maintained releases may also receive fixes when practical. Please allow reasonable time for triage and remediation before public disclosure.
