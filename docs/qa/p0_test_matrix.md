# مصفوفة اختبار P0 لإصدار v1

> **الغرض:** توثيق الاختبارات التي يجب تنفيذها على أجهزة حقيقية قبل أي اختبار مغلق أو إنتاج.  
> **القاعدة:** لا يساوي نجاح CI نجاح الأذان أو الحساسات أو البطارية على جهاز المستخدم.

## 1. بيئات الاختبار الإلزامية

| المعرف | البيئة | الهدف | الحالة لكل RC |
|---|---|---|---|
| DEV-26 | Android API 26 هاتف فعلي أو معتمد | الحد الأدنى للتوافق، الإشعارات والخلفية. | لم يبدأ. |
| DEV-30 | Android API 30 | الصلاحيات والتخزين والموقع. | لم يبدأ. |
| DEV-33 | Android API 33 | إذن الإشعارات وقنواتها. | لم يبدأ. |
| DEV-35+ | Android حديث | قيود foreground service والتنبيه الدقيق وتغيرات السلوك. | لم يبدأ. |
| OEM-BATTERY | جهاز بسياسة بطارية صارمة | Doze/قتل الخلفية والتنبيهات. | لم يبدأ. |
| LARGE-RTL | جهاز لوحي أو split-screen بالعربية | التخطيط، RTL، وتكبير النص. | لم يبدأ. |
| A11Y | TalkBack وSwitch Access | الإتاحة لمسارات P0. | لم يبدأ. |
| OFFLINE | جهاز في وضع الطيران | القراءة والمواقيت والقبلة المحلية. | لم يبدأ. |

## 2. حالات قبول الأذان والمواقيت

| المعرّف | الحالة | الخطوات المختصرة | المتوقع | الدليل |
|---|---|---|---|---|
| PRY-001 | إعداد أولي يدوي | أدخل مدينة أو إحداثيات، اختر الطريقة، احفظ. | تظهر أوقات اليوم والصلاة القادمة بلا شبكة. | لقطة + إصدار/جهاز. |
| PRY-002 | رفض الموقع | ارفض إذن الموقع في أول تشغيل. | يبقى الإدخال اليدوي متاحًا ولا يحدث crash. | تسجيل QA. |
| PRY-003 | أذان افتراضي | فعّل الأذان، اختر صوتًا مضمّنًا، واضغط «تحقق الآن» ثم «اختبر». | كل شروط الجاهزية المفترضة تظهر، ويسمع صوت المنبّه. | فيديو قصير أو توقيع المختبر. |
| PRY-004 | قناة معطلة | عطّل قناة الأذان من النظام ثم نفذ التحقق. | يظهر سبب واضح وخطوة إصلاح ممكنة. | لقطة. |
| PRY-005 | مستوى منبّه صفر | اخفض Alarm volume إلى صفر ثم نفذ التحقق. | يكتشف الاختبار المستوى غير المسموع؛ لا يدّعي الجاهزية. | لقطة. |
| PRY-006 | Doze والقفل | اقفل الهاتف وفعّل Doze حسب إجراءات QA ثم انتظر وقت تنبيه اختباري. | لا crash؛ إن منع النظام التنفيذ يظل السجل/الإرشاد صادقًا. | logcat ونتيجة. |
| PRY-007 | إعادة التشغيل | أعد تشغيل الجهاز بعد جدولة أوقات مستقبلية. | يعاد جدولة التنبيهات وتحديث widget/countdown. | لقطة بعد reboot. |
| PRY-008 | تغير الوقت والمنطقة | غير المنطقة الزمنية والوقت ثم أعد التطبيق. | تعاد الحسابات والتنبيهات من دون تكرار أو وقت قديم. | مقارنة قبل/بعد. |
| PRY-009 | خيار صامت/اهتزاز | اختر Silent ثم Vibrate only للصلاة القادمة. | السلوك يطابق الاختيار؛ لا يتوقع صوت في وضع صامت. | توقيع المختبر. |
| PRY-010 | سماعات/Bluetooth | جرّب الاختبار مع مكبر الهاتف وسماعة سلكية وBluetooth حيث متاح. | يُسجل مسار الصوت الفعلي وأي قيد للنظام. | سجل الجهاز. |

## 3. حالات قبول القرآن والصوت والبيانات

| المعرّف | الحالة | المتوقع |
|---|---|---|
| QUR-001 | وضع الطيران بعد أول تشغيل | يفتح النص العربي والحفظ والتقدم دون طلب شبكة أو crash. |
| QUR-002 | تنزيل صوت ثم قطع الشبكة | يظهر فشل قابل لإعادة المحاولة؛ لا يتعامل مع ملف جزئي كتنزيل مكتمل. |
| QUR-003 | مقاطعة صوتية | عند مكالمة/تنبيه/أذان، يطبق audio focus السلوك المعلن ويستأنف فقط إن كان مناسبًا. |
| QUR-004 | مساحة منخفضة | يعرض التطبيق خطأ مفهومًا ولا يفقد التنزيلات أو التقدم. |
| QUR-005 | ترقية إصدار | تظل العلامات والتقدم والإعدادات قابلة للقراءة بعد تحديث RC. |
| QUR-006 | حديث كبير | لا تتجمد الواجهة عند استيراد/بحث corpus؛ يظهر تقدم وإعادة محاولة. |

## 4. حالات قبول القبلة والإتاحة

| المعرّف | الحالة | المتوقع |
|---|---|---|
| QIB-001 | GPS متاح | تحدد الموقع وتحسب القبلة مع مؤشر معايرة مناسب. |
| QIB-002 | GPS مرفوض | يظل اختيار الموقع اليدوي متاحًا. |
| QIB-003 | حساس ضعيف/غير معاير | لا يقدم التطبيق ثقة زائفة؛ يظهر إرشاد معايرة أو حد واضح. |
| A11Y-001 | TalkBack | يمكن إنهاء إعداد الموقع، اختبار الأذان، فتح القرآن والبحث والحفظ بالتنقل الخطي. |
| A11Y-002 | تكبير الخط | لا نص مقطوع أو زر غير قابل للوصول في المسارات P0. |
| A11Y-003 | Switch Access | العناصر القابلة للنقر قابلة للوصول مرة واحدة وبترتيب منطقي. |

## 6. قاعدة الحجب

لا يمر RC إلى اختبار مغلق إن كانت أي حالة من PRY-001 إلى PRY-008 أو QUR-001 أو QUR-005 أو A11Y-001 غير منفذة أو فاشلة بلا استثناء معتمد. ولا يمر إلى الإنتاج إذا بقي عيب P0 مفتوحًا.
