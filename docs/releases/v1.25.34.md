## Muslim v1.25.34

### Five-Prayer Home Experience

This release refines the Prayer Times home screen around the five daily prayers and improves how the interface adapts across different Android screen sizes.

- Removes **Sunrise** from the visible daily prayer timetable, leaving **Fajr, Dhuhr, Asr, Maghrib, and Isha**.
- Prevents Sunrise from being selected as the Home screen's **next prayer**.
- Keeps Sunrise available internally for prayer-calculation and astronomical logic where needed.
- Aligns shared/exported daily schedules with the same five-prayer presentation used on screen.

### Responsive Layout Improvements

- Adds adaptive sizing for narrow phones, compact-height devices, and wider displays.
- Dynamically adjusts horizontal page padding, prayer-row density, typography, icons, and decorative ornaments.
- Improves the date and location header so long city names use space more intelligently and truncate cleanly when necessary.
- Reduces crowding on smaller screens while preserving clear hierarchy and accessible interaction targets.
- Keeps the upcoming prayer visually emphasized without making the timetable feel oversized or unbalanced.

### Expanded Prayer Notification

- Uses more of the horizontal space available inside Android's custom expanded notification area.
- Reduces unnecessary internal left/right padding and spacing between the five prayer cards.
- Slightly increases card height and prayer text sizes for better readability.
- Preserves equal-width prayer cards, RTL/LTR support, live remaining/elapsed timers, and the current next/missed-prayer highlighting.
- Maintains the application's existing light/dark notification styling and Islamic visual language.

> On Android 12 and newer, the outer notification-template margin is controlled by SystemUI. This release minimizes the app's own internal padding so the five-prayer layout uses the maximum practical width available.

### Reliability and Verification

- Responsive Home changes passed **debug builds**, **unit tests**, **Android Lint**, and **Detekt**.
- Instrumented tests passed on **Android API 26** and **Android API 36**.
- Production publication remains protected by the repository's stable-signing and approved-content gates.
- The release workflow performs the production checks again before the tag and artifacts are published.
