## Muslim v1.25.33

### Prayer Countdown Notification — Five-Prayer Timeline

This release introduces a redesigned, more informative prayer notification built around the five daily prayers.

- Displays **Fajr, Dhuhr, Asr, Maghrib, and Isha horizontally** in the expanded notification.
- Shows the scheduled time directly beneath each prayer.
- Clearly highlights the **upcoming prayer** using the app's Islamic green and gold visual language.
- Marks the **most recently elapsed prayer** with a distinct semantic accent.
- Adds a live **remaining-time counter** beneath the upcoming prayer.
- Adds a live **elapsed-time counter** beneath the previous prayer.
- Keeps the collapsed notification compact and easy to scan.

### Unified App Visual Identity

- Notification colors now mirror the application's central **IslamicPalette** in both light and dark mode.
- Surfaces, borders, text hierarchy, primary green, gold accent, and semantic error colors are consistent with the rest of the app.
- RTL/LTR layout behavior has been refined for Arabic and other locales.
- The existing 12-hour / 24-hour time-format preference is respected throughout the notification.

### Performance Improvements

- Live counters now use Android's system **Chronometer** instead of rebuilding the entire notification every second.
- Full prayer-state recomputation has been reduced to once per minute while visible timers continue updating every second.
- This reduces unnecessary notification updates and background work without sacrificing live countdown accuracy.

### Prayer-State Reliability

- The notification snapshot now carries all five visible prayer times.
- Midnight rollover handling keeps tomorrow's Fajr and the previous day's Isha aligned with the exact next/missed prayer state.
- Sunrise remains excluded from the five-prayer strip while continuing to be available to the underlying prayer-calculation model.
