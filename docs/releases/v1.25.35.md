## Muslim v1.25.35

This release consolidates the latest completed feature work into `main` and delivers a major visual, accessibility, worship-flow, and reliability upgrade across the app.

### Islamic Visual System & Personalization

- Introduces a new app-wide Islamic decoration engine built with lightweight vector ornaments.
- Adds **nine selectable ornament styles**: Geometric, Arabesque, Stars, Andalusian, Mashrabiya, Ottoman, Mushaf, Royal, and Minimal.
- Adds **four ornament intensity levels**: Off, Subtle, Balanced, and Rich.
- Extends the visual system across major experiences including Quran, Adhkar, Hadith, Prayer Times, Qibla, Tasbih, Ramadan, Zakat, learning/reference screens, Settings, widgets, and Wear OS.
- Keeps sacred text visually prioritized while decorative elements remain theme-aware and performance-conscious.

### Adhkar Read-Aloud

- Adds optional **local Arabic text-to-speech** for adhkar, disabled by default.
- Adds selectable voice support, speech-speed control, and an in-app voice preview.
- When enabled with floating adhkar, the visible dhikr can be read automatically and the overlay closes after speech completes.
- Adds explicit play/stop behavior and lifecycle handling so speech stops cleanly when appropriate.
- Gracefully handles devices without an installed Arabic text-to-speech voice.

### Hadith Library

- Redesigns the Hadith collection gallery with a more polished heritage-inspired presentation.
- Replaces bundled bitmap book-cover assets with scalable native Compose artwork.
- Adds distinct visual identities for Hadith collections while keeping collection metadata authoritative.
- Improves layout hierarchy, spacing, typography, and responsiveness across the Hadith experience.

### Quran & Recitation

- Improves the reciter selector so each reciter is presented in a dedicated card with portrait treatment.
- Fixes recitation follow-along behavior so the active ayah remains visible while playback advances.
- Improves reader-state tracking and scrolling reliability during continuous recitation.

### Qibla & Nearby Mosques

- Refreshes the Qibla screen and compass with a more adaptive, balanced layout.
- Expands nearby-mosque search range support and adds a cleaner distance-selection flow.
- Adds a direct **View on map** action alongside navigation for discovered mosques.
- Improves nearby-mosque UI logic, loading/empty states, and automated coverage.

### Adhan & Prayer Notifications

- Improves Adhan playback lifecycle handling and makes stopping playback more reliable.
- Adds support for stopping Adhan through volume-key interaction and notification-dismissal flows.
- Adds a direct fallback session for more resilient playback behavior.
- Further refines the expanded next-Adhan notification to use available horizontal space more effectively.
- Preserves clear next/missed-prayer highlighting, elapsed/remaining timing, RTL/LTR behavior, and the five-prayer presentation.

### Prayer Home, Widgets & Wear OS

- Integrates the final responsive five-prayer Home refinements into the main branch.
- Improves adaptive sizing and consistency across phone layouts.
- Extends Islamic ornament styling to prayer widgets and related surfaces.
- Improves synchronization of appearance preferences with Wear OS.

### Quality, Stability & Maintenance

- Consolidates all completed feature and fix branches into `main`.
- Expands automated verification for Islamic visual identity, Adhan lifecycle, Hadith navigation, nearby mosques, responsive layouts, and other critical UI contracts.
- Removes obsolete temporary release workflow material from the source tree.
- Keeps the production release protected by stable-signing verification, unit tests, Android lint, Detekt, and emulator-based instrumentation tests before artifacts are published.

### Release Assets

The production workflow publishes signed artifacts after all release gates pass:

- `app-release.apk` — phone/tablet APK
- `wear-release.apk` — Wear OS APK
- `app-release.aab` — production Android App Bundle

Existing compatible installations can update in place using the stable signing identity.
