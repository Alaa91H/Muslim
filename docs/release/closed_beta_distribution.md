# توزيع Muslim — Beta المغلق

## القناة المعتمدة

توزع نسخة **Muslim — Beta** كـAPK تحديث للحزمة `org.muslim.app` إلى مختبرين مدعوين فقط. تستخدم الاسم الظاهر **Muslim**، وتثبت فوق الإصدار السابق فقط عند ارتفاع `versionCode` ومطابقة شهادة التوقيع. يولّد CI بعد اجتياز الجودة والمحاكي **حزمة مختبرين** تحتوي APK ودليل الاختبار وسجل المحتوى وبصمة build. تحفظ الحزمة 30 يومًا في GitHub Actions artifacts ولا تُنشر كـGitHub Release عام.

## شرط التوقيع الثابت

لأن بيانات التطبيق التجريبي وإعدادات الأذان محلية، يجب أن يحصل المختبر على تحديثات APK بالتوقيع نفسه كي لا يضطر إلى إلغاء التثبيت وفقد بياناته. لذلك مهمة `:app:assembleClosedBeta` ترفض التوقيع المؤقت.

| مكان الإعداد | المطلوب |
|---|---|
| محليًا | ملف `keystore.properties` غير متتبع يحتوي مسار المفتاح وكلمات مروره والاسم المستعار. |
| GitHub Actions | الأسرار `SIGNING_KEYSTORE` (Base64) و`SIGNING_STORE_PASSWORD` و`SIGNING_KEY_ALIAS` و`SIGNING_KEY_PASSWORD`. |
| CI | تنشئ مهمة `assembleClosedBeta` APK للحزمة الأساسية مع رقم إصدار أعلى وتتحقق من وجود هوية توقيع ثابتة. |

يجب استخدام مفتاح يملكه مالك المنتج ويحتفظ بنسخة احتياطية مشفرة منه خارج المستودع. لا تضع المفتاح أو كلمة المرور في Git أو issue أو قناة ملاحظات.

## دورة إصدار تجريبي

1. يدمج الإصلاح في `main` بعد مراجعة الكود.
2. تجتاز وظائف `quality` و`emulator-tests` في CI.
3. يبني `beta-apk` حزمة المختبرين بالتوقيع الثابت عند وجود أسرار التوقيع.
4. يرسل مسؤول الإصدار الحزمة للمختبرين المدعوين، مع checksum ودليل `README.md`.
5. يسجل كل مختبر نسخة التطبيق وجهازه ونتيجة الحالات الحرجة في `docs/qa/p0_test_matrix.md` أو issue منظم.
6. تصنف الملاحظات P0/P1/P2؛ لا يتوسع العدد عند عيب P0 مفتوح.
7. بعد الاستقرار يكمل المنتج بوابات الإنتاج المنفصلة؛ Beta لا تتحول تلقائيًا إلى عام.

## ما يرسله مسؤول الإصدار للمختبر

| الملف | لماذا |
|---|---|
| `Muslim-Beta.apk` | التطبيق القابل للتثبيت. |
| `README.md` | اختبار الأذان، تثبيت النسخة، وقالب البلاغ. |
| `content_manifest.json` | شفافية حول الأصول المضمّنة وحالة اعتمادها. |
| `build-info.txt` | commit وworkflow للربط بين البلاغ وartifact. |
| SHA-256 للـAPK | التأكد من أن الملف لم يتغير أثناء الإرسال. |

## حدود التوزيع

لا يجوز إرسال Beta إلى جمهور مفتوح أو استخدامها في قائمة متجر عامة قبل اكتمال: اعتماد مصدر/رخصة المحتوى، سياسة الخصوصية وData safety، اختبارات P0 على أجهزة فعلية، وقرار Play Console. لا يزيل وصف «تجريبي» أي التزام قانوني أو ديني تجاه المحتوى الموزع.
