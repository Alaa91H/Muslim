# ميثاق الإصدار التجريبي المغلق

> **الحالة:** مسار اختبار قابل للاستخدام اليومي من متطوعين محددين، وليس نشرًا عامًا أو بديلًا عن بوابات الإنتاج.  
> **اسم الحزمة التجريبية:** `org.muslim.app`، واسم التطبيق الظاهر: **Muslim**.

## الهدف

يوفر الإصدار التجريبي تجربة تطبيق كاملة للمختبرين: مواقيت الصلاة، الأذان بعد ضبط الجهاز، القراءة، القبلة، والتنزيلات المحلية. الهدف هو التحقق من السلوك الفعلي على أجهزة وبلدان ولغات مختلفة قبل فتح الإنتاج العام.

> لا يزيل الاختبار التجريبي أي التزام بحقوق المحتوى أو الخصوصية. المحتوى غير الموثق في سجل المحتوى يبقى حاجزًا أمام التوزيع العام والإنتاج، وتُجرى التجربة فقط مع مختبرين معلومين وتحت مسؤولية مالك المنتج حتى اكتمال الاعتمادات.

## نطاق التجربة

| المجال | متاح للمختبر | ما يجب الإبلاغ عنه |
|---|---|---|
| الأذان والمواقيت | إعداد المدينة/الموقع والطريقة، زر التحقق، واختبار الصوت. | الجهاز، Android، المنطقة الزمنية، نتيجة بطاقة التحقق، وحالة الصوت. |
| القرآن والحديث والأذكار | القراءة والبحث والحفظ والتنزيل حيث يظهر في النسخة. | أخطاء النص/الترجمة/المصدر، الأداء، البحث، والتنزيل. |
| القبلة | الموقع اليدوي أو GPS والبوصلة. | دقة الحساس، المعايرة، فشل الموقع، واتجاه الواجهة. |
| الإتاحة واللغة | العربية والإنجليزية، TalkBack، تكبير الخط. | نص مقطوع، ترتيب تركيز، أو وصف عنصر غير مفهوم. |
| الخصوصية | رفض الصلاحيات واختبار البدائل. | إذن غير مبرر، اتصال غير مفهوم، أو بيانات لا ينبغي طلبها. |

## ما لا يعد وعدًا في التجربة

| غير مشمول | السبب |
|---|---|
| ضمان أن النظام سيشغل الأذان في كل هاتف أو وضع بطارية | يختلف سلوك Android والشركات المصنعة؛ بطاقة التحقق توضح ما يمكن إصلاحه. |
| حكم ديني شخصي أو فتوى | المحتوى معلوماتي ومحدود بمصادره ومراجعته. |
| توزيع عام أو قبول متجر | يحتاج ذلك اعتماد المحتوى، سياسة الخصوصية، توقيع production، وPlay Console. |
| نسخ احتياطي/استرجاع سحابي | ليس جزءًا من v1 التجريبي ما لم يُنفذ ويُختبر بصورة مستقلة. |

## معايير اختيار المختبرين

| البعد | الحد الأدنى المطلوب |
|---|---|
| الأجهزة | API 26 و30 و33 و35+، مع جهاز واحد بسياسة بطارية صارمة إن أمكن. |
| اللغة | العربية والإنجليزية؛ لغات أخرى فقط إذا اعتمدت. |
| الموقع | مدن ومناطق زمنية مختلفة، وحالة سفر/تغير وقت واحدة على الأقل. |
| الإتاحة | مستخدم واحد على الأقل لتجربة TalkBack أو تكبير الخط. |
| الالتزام | موافقة على إرسال بلاغ منظم وإعادة اختبار الإصلاحات. |

## معايير قبول النسخة التجريبية

| الشرط | الحالة المطلوبة قبل تسليم APK للمختبرين |
|---|---|
| بناء Beta APK | ناجح من مهمة `:app:assembleBeta`. |
| اختبارات الوحدة وLint | ناجحة للإصدار المرشح. |
| جرد المحتوى | `scripts/verify_content_manifest.py` ناجح ومرفق مع الإصدار. |
| تثبيت يدوي | تثبيت واختبار Smoke على جهاز واحد على الأقل. |
| الشفافية | تعليمات واضحة بأن النسخة تجريبية وكيفية الإبلاغ عن العيوب وحدود المحتوى والصلاحيات. |
| الملاحظات | نموذج بلاغ/قناة دعم مذكورة في `beta_tester_guide.md`. |

## شرط الانتقال إلى الإنتاج

لا ينتقل هذا المسار إلى إصدار عام إلا بعد نجاح `:app:verifyProductionRelease`، اكتمال قائمة Play Console، واستكمال اختبارات P0 على الأجهزة الحقيقية. لا توجد استثناءات تلقائية لهذه البوابات.
