# نطاق الإصدار v1 وبوابة قرار الإطلاق

> **الحالة:** مسودة تنفيذية تبدأ بها دورة جاهزية المنتج.  
> **المالك:** مالك المنتج.  
> **آخر تحديث:** 25 أغسطس 2026.

## 1. غرض الإصدار

الإصدار **v1** هو تطبيق Android محلي أولًا يساعد المستخدم في العبادة اليومية ودراسة القرآن والحديث من دون اشتراط حساب. لا يُعتمد الإصدار لأن عدد الميزات كبير؛ بل لأن نطاقه المعلن قابل للاستخدام، والمحتوى المضمّن موثق، والمسارات الحرجة مستقرة على الأجهزة المدعومة.

> لا يقدّم التطبيق فتوى فردية، ولا يضمن تنفيذ النظام لكل تنبيه في كل سياسة بطارية، ولا يدّعي ترخيص محتوى لا يثبته سجل المحتوى.

## 2. نطاق v1 المقترح

| المجال | داخل v1 | خارج v1 أو يتطلب Feature flag |
|---|---|---|
| مواقيت الصلاة | حساب محلي، موقع محفوظ أو إدخال يدوي، اختيار الطريقة والعصر، تعديلات يدوية، عد تنازلي. | أي وعد بدقة مطلقة أو حكم فقهي شخصي. |
| الأذان والتنبيهات | أصوات مضمّنة مرخّصة، معاينة واختبار، بطاقة تحقق الجاهزية، اهتزاز وإعداد لكل صلاة. | ضمان التسليم تحت كل ROM أو وضع بطارية؛ يشرح التطبيق القيود. |
| القبلة | اتجاه محسوب محليًا وبوصلة مع معايرة وتحذير عند ضعف الحساس. | ادعاء دقة حساسات لا يملكها الجهاز. |
| القرآن | النص العربي، القراءة والبحث والعلامات واستئناف التقدم، وتنزيلات يختارها المستخدم. | ترجمة أو تفسير لا يثبت مصدره ورخصته وحالته في manifest المحتوى. |
| الحديث والأذكار | التصفح والبحث المحليان للمحتوى الذي يمر اعتماد المصدر والرخصة والمراجعة. | نسبة صحة/تخريج أو شمول أوسع من البيانات المراجعة. |
| التعلم والمراجع | الأدلة التعليمية المعتمدة والمصنفة بوضوح. | فتاوى مخصصة، أو محتوى لم يمر المراجعة. |
| الخصوصية | تشغيل دون حساب، بيانات محلية، شبكات اختيارية ومعلنة. | تحليلات سلوكية أو إعلانات أو نسخ احتياطي سحابي غير معلن. |

## 3. لغات الإطلاق

تعتمد العربية والإنجليزية كلغتي إطلاق إلزاميتين. لا يُسوّق دعم أي لغة إضافية بوصفها معتمدة حتى يكمل مراجع بشري قائمة التحقق اللغوية الخاصة بها.

| اللغة | قرار v1 | شرط الاعتماد |
|---|---|---|
| العربية | إلزامية | مراجعة محتوى ديني وواجهة RTL وإتاحة. |
| الإنجليزية | إلزامية | مراجعة تحريرية ومصطلحات دينية متسقة. |
| لغات أخرى | اختيارية بحسب السوق | glossary معتمد، تدقيق بشري للمسارات P0، واختبار واجهة. |

## 4. الأجهزة والمنصات المدعومة

| السطح | قرار v1 | شرط التفعيل |
|---|---|---|
| هاتف Android | إلزامي؛ minSdk 26 وtargetSdk الحالي 37. | اجتياز مصفوفة اختبار الأجهزة في `docs/qa/p0_test_matrix.md`. |
| Wear OS | منفصل عن اعتماد الهاتف. | اختبار جهاز فعلي ومسار إصدار/خصوصية مستقل. |
| Android Auto | لا يعرض إلا المحتوى الصوتي المكتمل محليًا. | اختبار host فعلي أو بيئة معتمدة. |
| أجهزة لوحية وشاشات كبيرة | مدعومة ضمن Compose responsive. | اختبار المسارات P0 في split-screen وتكبير النص. |

## 5. بوابات القرار

لا ينتقل الإصدار إلى اختبار مغلق أو إنتاج إلا إذا كان كل بند في البوابة المقابلة مكتملًا ومثبتًا برابط دليل.

| البوابة | المطلوب | دليل الإغلاق |
|---|---|---|
| G0 — نطاق | لا شاشات تجريبية ظاهرة في v1، ولا ادعاءات تتجاوز التنفيذ. | مراجعة هذا الملف و`docs/release/claim_register.md`. |
| G1 — محتوى | كل أصل ظاهر يملك مصدرًا ورخصة وحالة مراجعة. | `docs/content/content_manifest.yaml` وتوقيع المراجعين. |
| G2 — موثوقية | اجتياز حالات P0 على أجهزة واقعية وتلقائية. | نتائج `docs/qa/p0_test_matrix.md` وتقارير CI. |
| G3 — امتثال | سياسة الخصوصية وData safety والصلاحيات متطابقة مع السلوك. | `docs/privacy/data_inventory.md` وقائمة Play Console. |
| G4 — إصدار | AAB إنتاجي موقّع بمفتاح غير debug، وفحص artifact ناجح. | run CI وSHA-256 للحزمة وشهادة التوقيع. |
| G5 — المتجر | قائمة المتجر، الأصول، التصنيف، والجمهور ومراجعة pre-launch مكتملة. | `docs/release/play_console_checklist.md`. |
| G6 — تشغيل | دعم وhotfix وrollout/rollback محددة. | `docs/release/release_runbook.md`. |

## 6. قرار النطاق الذي يحتاج اعتماد مالك المنتج

على مالك المنتج توثيق القرار النهائي لكل عنصر أدناه قبل دمج الإصدار المرشح. حتى ذلك الحين، يعد القرار في هذا الملف افتراضًا محافظًا.

| القرار | الافتراض التنفيذي الحالي | الحالة |
|---|---|---|
| بلدان الإطلاق الأولى | إطلاق عالمي محدود مع العربية والإنجليزية فقط كضمان لغوي. | يحتاج اعتماد. |
| جمهور الأطفال | لا يُستهدف الأطفال صراحة في v1. | يحتاج اعتماد. |
| تقارير الأعطال | قناة اختيارية، مجهلة قدر الإمكان، أو دعم يدوي فقط. | يحتاج اعتماد. |
| النسخ الاحتياطي | ليس وعدًا في v1 ما لم ينفذ تصدير/استيراد مشفر مع اختبارات استرجاع. | معتمد افتراضيًا. |
| التلاوات والترجمات والتفسير | لا يظهر إلا المحتوى الذي يملك سجل رخصة وحالة اعتماد. | معتمد افتراضيًا. |

## 7. قاعدة تغيير النطاق

أي إضافة إلى v1 تتطلب بطاقة تغيير تتضمن: الهدف، المستخدم المتأثر، مصدر المحتوى ورخصته إن وجدا، صلاحيات/شبكة جديدة، حالات اختبار، تغيير سياسة الخصوصية وData safety، وقرارًا صريحًا من مالك المنتج. لا تدمج ميزة جديدة في فرع الإصدار من دون هذه البطاقة.
