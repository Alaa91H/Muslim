# سجل ادعاءات المنتج — v1

> **الغرض:** منع النصوص التسويقية أو عناوين الواجهات من تجاوز ما يثبته التطبيق والمحتوى والاختبارات.  
> **المالك:** مالك المنتج، مع اعتماد تقني ومحتوى/ترخيص عند اللزوم.  
> **قاعدة النشر:** لا يستخدم أي ادعاء في المتجر أو README أو واجهة المستخدم قبل اكتمال دليل الحالة.

## سير اعتماد الادعاء

| الخطوة | المسؤول | المخرج |
|---|---|---|
| اقتراح النص | منتج/تسويق | نص باللغتين العربية والإنجليزية وسياق ظهوره. |
| فحص التنفيذ | قائد تقني | رابط اختبار أو تنفيذ يثبت الادعاء. |
| فحص المحتوى والترخيص | مراجع المحتوى/الترخيص | مصدر ورخصة وحدود علمية. |
| فحص الخصوصية | مسؤول الخصوصية | أثر على data safety والسياسة إن وجد. |
| الاعتماد | مالك المنتج | تغيير الحالة إلى «معتمد» مع تاريخ وإصدار. |

## حالات السجل

| الحالة | المعنى |
|---|---|
| مفتوح | لا يظهر في المتجر ولا يرفع إلى وصف نهائي. |
| قيد المراجعة | يوجد دليل أولي لكنه غير معتمد. |
| معتمد | اكتمل الدليل والمراجعة ويمكن استخدام النص المحدد فقط. |
| مرفوض | النص مضلل أو لا يملك دليلًا أو ترخيصًا كافيًا. |
| متوقف | كان معتمدًا ثم أوقِف بسبب محتوى أو عيب أو تغير نطاق. |
